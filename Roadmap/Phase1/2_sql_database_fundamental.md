# SQL and database fundamentals

First principle: a database exists to store facts and retrieve the right facts efficiently and consistently.

Learn:

- Tables, rows, columns, primary keys and foreign keys.
- SQL SELECT, JOIN, GROUP BY, subqueries and CTEs.
- Window functions, indexes and query execution plans.
- Transactions, constraints, normalization and data integrity.
- Connection pooling and parameterized queries.
- Why slow queries, duplicate records and missing values matter.

Hands-on lab:

- extend the ticket system with customers, tickets, status history and response-time analytics.

Write queries to answer:

    - Which customers generate the most tickets?
    - What is the average resolution time by priority?
    - Which tickets breached the SLA?
    - Which records are duplicated or incomplete?
